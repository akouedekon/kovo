CONTRIBUTING to Kovo

Merci de contribuer à Kovo !

Guides rapides:

- Forkez le dépôt, créez une branche feature/bugfix (ex: feature/login-otp).
- Assurez-vous que les tests passent localement (backend: mvn test, mobile: flutter test, admin: npm test).
- Respectez le style de code existant. Ajoutez des tests pour les nouvelles fonctionnalités quand possible.
- Faites une Pull Request détaillée: but, changements clés, instructions pour tester.

Communication:
- Ouvrez une issue avant d'implémenter une grosse fonctionnalité pour discussion.
